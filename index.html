MiniBrain

Building a brain, one function at a time

A learning project: code a scaled-down artificial brain on a laptop, step by step. Every step has a live demo you can play with, and compares what we built with the real human brain.

The honest starting point. A full human brain has about 86 billion neurons and 100 trillion connections. Just storing one number per connection would take hundreds of terabytes, around 10,000× more memory than a MacBook has. So we build a scaled-down brain: small circuits, each faithful enough to reproduce a real thing brains do.

Three ideas that explain most of the brain

1. A neuron is a leaky bucket

Inputs pour charge in, and it slowly leaks out. When the level reaches the brim, the neuron fires a spike (a 1-millisecond electrical click), empties, and starts again.

2. A synapse is a volume knob

Every connection has a strength. Learning is turning knobs. If neuron A keeps helping B fire, A→B gets louder. Memories live in the knob settings.

3. Regions are specialist teams

Vision, memory and decision teams each run their own circuits and pass messages along long cables, like departments in a company.

How to use this site

  1. Do the steps in order. Each builds on the one before.
  2. On each page, read the analogy first, then play with the live demo before reading the equations.
  3. Do the “Try this” experiments, then the quick check at the end.
  4. The code is in assets/sim/: short, commented, and readable.
