Working memory

Holding a thought after the input is gone.

You'll learn

  • How neurons keep firing with nothing to look at
  • Why memories get fuzzier the longer you hold them
  • Why slow synapses matter, and what distraction does
  • The Python behind a “bump attractor”

The idea

Working memory is an echo that keeps itself going. A flash starts a group of neurons firing, and they keep re-exciting each other after the flash is gone.

  • Neighbours excite each other, so the echo stays in one place: a “bump” of activity.
  • Everyone inhibits everyone, so only one bump survives, and quiet stays quiet.
  • Random noise nudges the bump, so the memory slowly drifts.

New tool: rate models

From this step, each neuron is described by its firing rate (Step 1's “how often”) instead of every single spike. Rates change smoothly, so big circuits run fast. It's how most large brain models work.

How real working memory works

  

    
1. Neurons that keep firing

    
In 1989, recordings from monkeys doing this exact task found prefrontal cortex neurons that fired through the whole delay, each one for its own location. When they stopped early, the monkey made a mistake.

  

  

    
2. Why slow synapses matter

    
    
      
  • Prefrontal circuits rely on NMDA receptors, whose currents last ~100 ms, far longer than the ~3 ms of Step 3's AMPA.
    • 
      
  • Slow currents smooth out noise, so the echo stays put.
    • 
      
  • Ketamine, which blocks NMDA receptors, impairs working memory in people. The fast-synapse setting is a toy version of that.
    • 
    

  

  

    
3. Memories drift

    
Ask people to remember a location, and their error grows with the delay. In 2014, researchers matched these errors to the random drift of bumps in monkey prefrontal cortex, the same drift as Demo 2.

The equations

  

    
Equation 1 · Each neuron's rate

    

      τ · dri/dt = −ri + f(Ii)
      Ii = Σj Wij rj + I0 + Icue + noise
    

    

      
riFiring rate of neuron i: 0 = silent, 1 = flat out.

      
fResponse curve: 0 below threshold, then rising and levelling off (tanh).

      
τHow fast rates follow their input. Set by the slow synapses.

      
I0 = −0.4Background input, just below threshold, so the ring rests quietly.

    

  

  

    
Equation 2 · The ring's wiring

    

      Wij = (J0 + J1 cos(θi − θj)) / N
    

    

      
θiThe direction neuron i prefers.

      
J1 = 12Reverberation: similar neurons excite each other.

      
J0 = −2Everyone inhibits everyone, so only one bump survives.

    

  

  

    
Equation 3 · Reading the memory out

    

      memory = angle of Σi ri · (cos θi, sin θi)
    

    
Each neuron “votes” for its direction, weighted by how fast it fires. This population vector is also how brain–computer interfaces read movement intentions.

Beyond the lab

  

    
Emerging tech

    
    
      
  • A real ring in a fly's brain. In 2015, scientists watched a bump of activity move around a literal ring of neurons in the fruit fly, tracking which way it faced. Step 11 explores the fly brain.
    • 
      
  • Robots with a sense of direction. Ring attractors have been run on neuromorphic chips to help robots keep track of their heading.
    • 
      
  • Reading intentions. Brain–computer interfaces decode movement with the same population-vector idea as Equation 3.
    • 
    

  

  

    
For good

    
    
      
  • Schizophrenia research. Working-memory problems are a core symptom. One leading idea is weakened NMDA signalling, which models like this make testable.
    • 
      
  • Ageing. In a 2019 study, gentle rhythmic brain stimulation briefly improved working memory in older adults.
    • 
      
  • ADHD. Common medications act on dopamine and noradrenaline in prefrontal cortex, which tune exactly these circuits.
    • 
    

  


  
Key terms

  

    

      
Working memory
Holding information in mind for seconds, to use it.

      
Persistent activity
Neurons that keep firing after the stimulus is gone.

      
Bump attractor
A self-sustaining bump of activity that can sit anywhere on a ring.

      
Prefrontal cortex
The front of the brain, key for working memory and planning.

      
NMDA receptor
A slow glutamate receptor. Its long currents steady persistent activity.

      
Rate model
Describes neurons by firing rate instead of individual spikes.

      
Population vector
Reading a value out by letting each neuron vote for its preference.

      
Drift
Slow random wandering of a held memory.
