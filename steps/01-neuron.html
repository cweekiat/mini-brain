Step 1 · Cellular level

One neuron

Everything the brain does, from seeing to remembering to deciding, is built from one trick, repeated 86 billion times. This step builds that trick.

The big idea

A neuron is a leaky bucket. Inputs pour water in, and a small hole lets it drain out. If water pours in faster than it leaks, the level rises until it hits the brim, and then the bucket tips over: that's a spike. It empties, and the filling starts again.

Three things follow from that one picture, and all three are true of real neurons:

  • All or nothing. A bucket either tips or it doesn't. A spike is always the same size. A stronger input doesn't make a bigger spike, it makes more spikes.
  • Weak inputs are forgotten. A trickle drains away as fast as it arrives and never reaches the brim. The neuron ignores it.
  • Strength becomes rhythm. The harder you pour, the faster it fills and the more often it tips. The brain encodes “how much” as “how often”.

Try this

  1. Input at 1.2. The level rises and stalls below the brim. No spikes: the trickle leaks out as fast as it comes in. Press Zap and watch one pulse push it over.
  2. Slowly raise the input. Find the exact point where it starts firing (about 1.5 nA). Below that, nothing at all. That is the threshold.
  3. Keep raising it. The spikes get closer together but never taller. All or nothing.
  4. Put input back to 1.2, then drag the leak speed up to 50. A slow leak lets small inputs add up, so the same trickle now fires. Real neurons tune this.
  5. Set input to 1.3 and noise to 2. It fires now and then, at random. Real neurons in your cortex look exactly like this.

What a real neuron actually is

The bucket is a cartoon, so here's the real thing. A neuron is a cell wrapped in a thin fatty membrane. Inside there's more potassium, outside more sodium. That imbalance makes the inside sit at about −70 millivolts compared with the outside: the “empty bucket”.

The membrane is studded with tiny protein doors called ion channels. Two kinds make the spike:

  • Sodium (Na⁺) channels open when the voltage rises a little. Sodium rushes in, which raises the voltage more, which opens more channels. This chain reaction is the spike shooting up to about +40 mV.
  • Potassium (K⁺) channels open a moment later. Potassium flows out and drags the voltage back down, even a little below rest. Meanwhile the sodium channels jam shut for a millisecond or two, so the neuron can't fire again straight away (the refractory period).

In 1952, Alan Hodgkin and Andrew Huxley measured these currents in a squid's giant nerve fibre and wrote equations that reproduce the spike precisely. They won the Nobel Prize for it. Demo 2 runs those exact equations.

Try this

  1. Press Zap. Watch the orange sodium current surge first, then the purple potassium current pull the voltage back down. That's the whole spike.
  2. Look at the end of the spike. The voltage dips below rest before it recovers. Real neurons do this too (the “afterhyperpolarisation”). The bucket model can't.
  3. Press Two zaps. The second zap arrives during the refractory period and does almost nothing. This is why a neuron can't fire more than a few hundred times a second.
  4. Tick block sodium and zap. Nothing. No sodium, no spike, no signal. That's exactly how a local anaesthetic stops pain reaching your brain.
  5. Tick block potassium instead and zap. The spike gets wider and slower to end. Without its brake, the neuron struggles to reset.
  6. Raise the steady input slowly from 0. Notice it doesn't start at a slow rhythm: it jumps straight to about 60 spikes a second near 6–7 µA/cm². Squid axon neurons really behave this way. Demo 3 shows the difference.

What we left out (on purpose)

  • Dendrites. Real branches do their own mini-computations before signals even reach the cell body. Some researchers think one real neuron is as smart as a small artificial neural network.
  • The dozens of other ion channel types (calcium, slow potassium…). These give real neurons habits like bursting and getting tired.
  • Chemistry and energy. Neurotransmitters, ion pumps, blood supply.

The rule this project follows: keep only the detail the function needs. For brain waves, memory and decisions, the bucket is enough, so from Step 3 on we'll use it to fit thousands of neurons on a laptop.

The code

The whole bucket neuron is about ten lines. From assets/sim/neuron.js:

step(dt, I) {
  if (this.refLeft > 0) {               // just fired? stay silent
    this.refLeft -= dt; this.V = this.Vreset; return false;
  }
  // leak back toward rest + fill from the input
  this.V += (dt / this.tau) * (-(this.V - this.EL) + this.R * I);
  if (this.V >= this.Vth) {             // reached the brim?
    this.V = this.Vreset;               // tip over and empty
    this.refLeft = this.tRef;           // start the silent period
    return true;                        // SPIKE
  }
  return false;
}
The equation, in plain words

τ · dV/dt = −(V − EL) + R · I

“How fast the level changes” = “leak back toward rest” + “fill from input”. τ (tau) sets how quickly both happen. When V passes the threshold, record a spike and reset. Every step, the computer nudges V forward by a tiny slice of time (dt = 0.1 ms). That's called numerical integration, and it's how every brain simulator works.

The steady level the bucket settles at is EL + R·I. It reaches the brim when R·I = 15 mV, so I = 1.5 nA. That's the threshold you found by hand in “Try this”.
