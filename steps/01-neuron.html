The idea

A neuron is a leaky bucket. Input fills it, a hole drains it. When it reaches the brim, it tips over: a spike.

  • All or nothing. Every spike is the same size.
  • Weak input fades. It leaks out before reaching the brim.
  • Stronger input means more spikes, not bigger ones.

The real neuron

A neuron sits at about −70 mV inside. Tiny doors in its membrane, called ion channels, make the spike:

  • Sodium flows in. Voltage shoots up to about +40 mV.
  • Potassium flows out. Voltage falls back down.
  • Sodium doors jam shut for 1–2 ms, so it can't fire again straight away.

Hodgkin and Huxley wrote these equations in 1952 from a squid's nerve, and won a Nobel Prize. Demo 2 runs them.

How it's coded

Each thing a real neuron does becomes a few lines of code. Simplified from neuron.js.

BIOLOGY · Charge leaks out, input flows in

1. Integrate


// every 0.1 ms step:
// leak back to rest + fill from input
V += (dt / tau) *
     (-(V - V_rest) + R * input);

One line is the whole “leaky bucket”. tau is the Leak time slider.

BIOLOGY · A spike is all-or-nothing

2. Fire and reset


// reached the brim?
if (V >= threshold) {
  spikes.push(t); // same every time
  V = V_reset;    // empty the bucket
}

A spike is just a timestamp. Size never changes, only timing.

BIOLOGY · It can't fire again for ~2 ms

3. Refractory period


// fired very recently?
if (refractoryLeft > 0) {
  refractoryLeft -= dt; // countdown
  return;               // ignore input
}

A countdown timer. This caps the firing rate at a few hundred Hz.

BIOLOGY · Sodium doors open as voltage rises

4. Ion channel gates


// m = share of sodium gates open (0–1)
m += dt * (open(V) * (1 - m)
         - close(V) * m);
// more open gates, more sodium in
I_Na = g_Na * m**3 * h * (V - E_Na);

Higher V opens more gates, which lets in more sodium, which raises V. This loop is the spike in Demo 2.

BIOLOGY · Lidocaine blocks sodium channels

5. A drug is one number


// block = 1 → I_Na = 0 → no spike
I_Na = g_Na * (1 - block)
     * m**3 * h * (V - E_Na);

The “Block sodium” switch in Demo 2 sets block to 1.

BIOLOGY · Stronger input, more spikes per second

6. Rate coding


function firingRate(input) {
  let count = 0;
  // simulate 1 second, count spikes
  for (let t = 0; t < 1000; t += dt)
    if (neuron.step(dt, input))
      count++;
  return count; // spikes/s (Hz)
}

Run this for every input level and you get the curves in Demo 3.

Why use the simpler bucket?

The bucket costs about 3 sums per time step. Real channels cost about 30. For circuits of thousands of neurons (Step 3 onward), the bucket keeps a laptop fast enough.

Left out on purpose: dendrite branches, dozens of other channel types, neurotransmitters, energy use.

Key terms

Membrane potential
Voltage inside the cell compared with outside.
Resting potential
About −70 mV when the neuron is quiet.
Threshold
The voltage where a spike becomes unstoppable.
Action potential (spike)
A 1 ms all-or-nothing voltage pulse.
Ion channel
A protein door that lets one kind of ion through.
Refractory period
The short time after a spike when it can't fire.
Firing rate
Spikes per second (Hz). Encodes input strength.
Go deeper: the equation

τ·dV/dt = −(V − EL) + R·I

Change in voltage = leak toward rest + input. The bucket settles at EL + R·I, so it fires when R·I > 15 mV, which is I > 1.5 nA. That's the threshold you found in Demo 1.

Computers can't do smooth time, so they take tiny steps (dt = 0.1 ms) and nudge V each step. This is called Euler integration, and it's how most brain simulators work.
