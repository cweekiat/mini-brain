Memory recall

Show half a memory, get the whole thing back.

You'll learn

  • How memories can live in synapses, not in single neurons
  • Why a small clue brings back a whole memory
  • Why memory fails slowly as synapses are lost
  • The Python behind a Hopfield network

The idea

A memory is a valley in a landscape. Start anywhere nearby and you roll down to the bottom: the full memory.

  • Storing uses Step 2's rule: neurons on together get linked. That digs a valley.
  • Recalling means each neuron follows the vote of its links. The picture rolls downhill.
  • Every synapse holds a little of every memory, so losing a few costs little.

How real memories work

  

    
1. Where this happens

    
A region called CA3, in the hippocampus, is wired a lot like our model: its neurons connect heavily to each other.

    
    
      
  • A smell or a song (a partial clue) re-activates some neurons.
    • 
      
  • Their links pull in the rest of the pattern: pattern completion.
    • 
      
  • A neighbouring region (dentate gyrus) makes similar memories more different before storing them, to avoid the mix-ups you saw.
    • 
    

  

  

    
2. Memories live in the connections

    
No single neuron holds “heart”. The memory is spread over all 160,000 links. That's why:

    
    
      
  • Losing some synapses blurs memory slowly instead of deleting it.
    • 
      
  • Similar memories interfere: they share many of the same links.
    • 
      
  • There's a limit: about 0.14 memories per neuron in this model.
    •

The equations

  

    
Equation 1 · Storing (Hebb's rule)

    

      Wij = 1⁄N Σμ pμi pμj
    

    

      
pμiPixel i of memory μ: +1 on, −1 off.

      
WijLink from neuron j to i. Positive if they tend to agree.

      
Wii = 0No neuron talks to itself.

    

  

  

    
Equation 2 · Recalling

    

      hi = Σj Wij sj
      si ← sign(hi)
    

    

      
hiThe vote: total input to neuron i.

      
sign+1 if the vote is positive, −1 if negative.

    

    
This is the leaky bucket from Step 1, shrunk to its essence: fire if the input is above zero.

  

  

    
Equation 3 · Energy

    

      E = −½ Σi,j Wij si sj
    

    
Each update can only lower E or keep it the same, so recall always settles. Stored memories sit at the bottoms of valleys. Hopfield's 1982 insight was exactly this.

  


  
Real vs our model

  

    
Neurons
RealSpiking, with timing (Steps 1–3).
Our modelOn/off only. Fire if the vote is positive.

    
Wiring
RealCA3: each neuron reaches only a few percent of others. Links are one-way.
Our modelEveryone linked to everyone, both ways equal.

    
Capacity
RealUnknown, helped by sparse codes and pattern separation.
Our model~0.14 × N ✓ (classic result)

    
Damage
RealIn Alzheimer's, synapse loss tracks memory decline.
Our modelGraceful decline with synapse loss ✓

  


  
Beyond the lab

  

    
Emerging tech

    
    
      
  • Nobel Prize, 2024. John Hopfield (this network) and Geoffrey Hinton (who built on it) won the Physics prize for foundations of today's AI.
    • 
      
  • Hidden inside AI. The “attention” step in modern language models can be read as a modern Hopfield network that recalls the best-matching memory.
    • 
      
  • Computing in memory. Grids of memristors store W as resistances and compute the vote W · s in one step, saving the energy spent moving data.
    • 
    

  

  

    
For good

    
    
      
  • Alzheimer's research. Loss of synapses is one of the strongest signs of memory decline. Models like Demo 2 help explain why early losses go unnoticed.
    • 
      
  • Memory prostheses. In a small 2018 study, an implant that mimicked hippocampal activity improved some people's short-term memory scores by about a third.
    • 
      
  • Robust hardware. Systems that fail gracefully, like this network, are valuable in medical and space electronics.
    • 
    

  


  
Key terms

  

    

      
Hopfield network
A fully connected network that stores patterns as stable states.

      
Attractor
A state the network settles into, like the bottom of a valley.

      
Pattern completion
Recovering a whole memory from part of it.

      
Energy
A score that only goes down during recall. Memories are its minima.

      
Overlap
How alike two patterns are: 1 = identical, 0 = unrelated.

      
Capacity
How many memories fit before recall breaks down.

      
Spurious state
A false valley: a blend of memories.

      
Hippocampus (CA3)
A brain region key for forming and recalling memories.
